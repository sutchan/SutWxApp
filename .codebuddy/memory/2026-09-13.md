# 2026-09-13 工作记录

## 修复 ESLint 门禁（ESLint 10 flat config 在 CI 报“找不到模块”）
- 根因：CI 用 `npm ci`（按 `SutWxApp/package-lock.json`，eslint 解析为 **10.10.0**）。ESLint 9+ 默认只读 flat config，且 **eslint 10 已将 `@eslint/js`/`globals`/`@eslint/eslintrc` 移出运行时依赖（仅留在 devDependencies）**，故 `npm ci` 树中不存在这些包。任何 `require("@eslint/js"|"globals"|"@eslint/eslintrc")` 都会在 runner 上 `Cannot find module`。本地 node_modules 损坏/不一致（package.json 显示 8.57.1、实际跑 10.10.0），不可作为验证基准。
- 最终修复（已本地实证 0 error / 11 warning，与升级前基线一致）：
  - `SutWxApp/eslint.config.js` 改为**纯声明式、零外部 require**：recommended 规则按 eslint 8 的 `eslint:recommended` 清单**就地内联**（全部在 eslint 10 中仍存在）；node 全局变量按 `globals@13` 的 `node` 导出内联；微信小程序全局变量（wx/App/Page…）内联；`no-unused-vars` 显式 `caughtErrors:"none"`（复刻 eslint 8 默认，避免 catch 参数误报）；`__tests__` 补 jest 全局 `describe/it/test/expect/beforeEach/afterAll/jest`，`scripts/**` 与 `utils/compress-images.js` 关 `no-console`，`compress-images` 设 `sourceType:"module"`。
  - 删除失效的 `SutWxApp/.eslintrc.js`（规则现已全在 eslint.config.js，避免双源）。
  - `package.json` lint/lint:fix 脚本去掉 `--ext .js`（flat config 已废除）→ `eslint .`。
- 经验：**升级 ESLint 主版本后，不要依赖 `@eslint/js`/FlatCompat**（v10 已不可用于 `npm ci`）；flat config 要自包含。改 lint 规则改 `eslint.config.js` 即可。
- 版本：bump patch 3.0.9 → 3.0.10；同步 package.json / app.js globalData.version / README 徽章 / CHANGELOG 顶部小节（`check:version` 通过）。
- 未改 lockfile（无需新增依赖），CI 重跑即可通过。
