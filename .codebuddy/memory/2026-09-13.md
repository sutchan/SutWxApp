## 修复 ESLint 10 flat config 报错（lint 门禁恢复）
- 现象：`npm run lint`（即 `eslint . --ext .js`）报 `ESLint couldn't find an eslint.config.* file`，因 `package.json` devDependencies 为 `eslint: ^10.10.0`，ESLint 9+ 默认只读 flat config（eslint.config.*），而项目仅有遗留 `.eslintrc.js`（eslintrc 格式），不再被自动识别。
- 修复：
  - 新增 `SutWxApp/eslint.config.js`（flat config），用 `FlatCompat`（`@eslint/eslintrc`）+ `js.configs.recommended`（`@eslint/js`）复用 `SutWxApp/.eslintrc.js` 的全部规则 / globals / overrides；`.eslintrc.js` 保留为规则单一来源，不再被 ESLint 9+ 自动读取（被 flat config 包裹调用）。
  - `package.json` 的 `lint`/`lint:fix` 脚本去掉 `--ext .js`（flat config 下该 flag 已移除）→ 改为 `eslint .` / `eslint . --fix`。CI（`.github/workflows/ci.yml`）用的是 `npm run lint`，同步生效。
- 版本：新增配置文件属项目修改，按规则 bump patch 3.0.9 → 3.0.10；同步 package.json / app.js globalData.version / README 徽章 / CHANGELOG 顶部小节（check:version 通过）。`.eslintrc.js` 头注释未改（未编辑该文件）。
