## 验收标准（生产上线门禁）

1. **发布配置**：真实 AppID + 合法域名 + 环境配置表三要素齐备，体验版可真机访问全部端点。
2. **合规**：隐私保护指引过审、类目资质报备通过、用户协议与售后政策可访问。
3. **交易闭环**：真实环境完成支付到发货、确认收货、退款全链路，掉单由 cron 兜底自动修复。
4. **可观测**：服务端错误日志可查、`/api/health` 拨测正常、客户端监控上报可达后端并可聚合。
5. **安全**：限频分档生效并演练；支付审计清单全部打勾；密钥轮换流程文档化。
6. **质量门禁**：CI 五 Job 全绿（含 PHP 八套件）；`npm test` 不低于 145 用例（含新增支付异常路径）；无 worker 泄漏告警；主包体积不超过 1.5M。
7. **运维**：runbook 覆盖安装、升级与回滚；发布流水线一键出包并附 Release Notes。
