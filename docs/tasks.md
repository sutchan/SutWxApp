## 验收标准（生产上线门禁）

### 已达成（归档基线，不再重复建设）

- **可观测**：服务端结构化日志、`/api/health` 拨测、客户端监控上报可达后端（BE-010 / OPS-006）。
- **安全**：限频分档生效、支付审计清单补齐、密钥轮换流程文档化（SEC-001~004）。
- **发布工程**：runbook 覆盖安装 / 升级 / 回滚；`auto-release.yml` 自动出包并附 Release Notes（OPS-004~008、3.5.13）。

### 待验证（上线门禁）

1. **发布配置**：真实 AppID + 合法域名 + 环境配置表三要素齐备，体验版可真机访问全部端点。
2. **合规**：隐私保护指引过审、类目资质报备通过、用户协议与售后政策可访问。
3. **交易闭环**：真实环境完成支付到发货、确认收货、退款全链路，掉单由 cron 兜底自动修复。
4. **质量**：CI 五 Job 全绿（含 PHP 八套件）；`npm test` 全量通过（当前基线 137 用例）、八项 `npm run check` 全绿、无 worker 泄漏告警；主包体积不超过 1.5M。
5. **staging 演练**：缓存命中率、限频触发与 `X-RateLimit-*` 头行为实测并完成基线记录（QA-009）。
