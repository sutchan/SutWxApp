## 1. 项目现状与开发进度总览

### 1.1 核心架构与定位
- **架构模式**: 纯前端微信小程序 + WordPress (WooCommerce) 作为 Headless CMS。
- **数据流**: 小程序通过 `/api/*` REST 接口从 WordPress 插件获取文章、分类、商品与主题数据；支持 `mock` 与 `woocommerce` 双数据源无缝切换。
- **设计系统**: Apple 极简主义设计语言，全站 CSS 变量化，支持 WordPress 后台动态换肤（5 套内置预设 + 自定义十六进制色值）。

## 4. 任务跟踪与验收标准

### 4.1 核心里程碑验收指标
1. **鉴权验收 (Milestone 1)**:
   - 小程序调用 `wx.login` 获取 code 发送给 `/api/v1/users/login`，插件成功下发有效 JWT。
   - 携带 `Authorization: Bearer <token>` 访问私有接口返回 200，伪造/过期 Token 返回 401 统一错误包络。
2. **性能与稳定性验收 (Milestone 2)**:
   - 启用 Transients 缓存后，商品与文章列表接口响应时间降至 200ms 以内。
   - 在 WordPress 后台编辑/发布文章或修改商品价格库存后，缓存立即清除，小程序刷新可见最新数据。
3. **测试覆盖率验收 (Milestone 3)**:
   - 前端工具类与模型映射测试行覆盖率 ≥ 80%。
   - CI 流水线在全量通过前禁止合入主分支。
