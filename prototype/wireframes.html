PART 04

组件使用规则

对齐 spec §3 设计原则、§4.1.3 语义色策略与 §8 脏值纠正清单；任何实现与本区冲突时以 spec.md 为准。

4.1

色彩使用三原则 · 废弃色警示区

中性 ≥ 85% · 主色绿 ≤ 10% · 语义色 ≤ 5%

✓CTA 一律绿

加购、立即购买、去支付、提交订单等一切转化按钮一律 --primary-color 绿 + 白字。同一屏最多一个实心绿大按钮；商品详情底栏允许「加购深绿 + 购买主色绿」双绿组合。

✓价格禁红

促销价/现价 = --primary-dark 深绿（¥ 小号 + 数字大号加粗）；原价 = --text-secondary + 删除线；折扣标签 = 浅绿底主色字。价格场景永不使用红色。

✓红仅危险

--error-color #F44336 仅用于表单校验错误、删除/退出登录确认、错误 toast。购物车角标是品牌计数用绿；红点（badge-dot）属警示语义可保留红。

4.4

安全区与底部固定栏公式

constant + env 双写法 · 内容区预留等高 padding-bottom
/* 底部固定栏（结算/操作栏）—— spec §5.11 */
.bottom-bar {
  position: fixed; bottom: 0; left: 0; right: 0;
  z-index: 100; background: #FFFFFF;
  padding: 16rpx 24rpx;
  padding-bottom: calc(16rpx + constant(safe-area-inset-bottom));
  padding-bottom: calc(16rpx + env(safe-area-inset-bottom));
}
/* 页面内容区需预留等高，避免遮挡 */
.content { padding-bottom: 120rpx /* + 安全区 */; }
/* 主按钮：高度 88rpx，圆角 44rpx（胶囊） */
· 涉及原生 tabBar 的页面无需额外处理（原生 tabBar 自带安全区）
· 自定义头部叠加在图片上时使用 .safe-area-top
· 弹层底部按钮区同样需要安全区 padding（见 2.5 演示）
页面内容区……底部预留 120rpx + 安全区，固定栏不遮挡末行内容。
safe-area-inset-bottom（安全区示意）
违规警示：忘记 env(safe-area-inset-bottom) 是高频缺陷；双按钮禁止橙+红配对（商品详情旧版），一律双绿方案。
