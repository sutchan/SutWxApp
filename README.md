# SutWxApp - 苏铁微信小程序

苏铁微信小程序 (SutWxApp) 是一款面向普通消费者的电商平台，专注于提供优质商品和购物体验。

## 项目结构

```
SutWxApp/
├── app.js          # 小程序入口文件
├── app.json        # 全局配置
├── app.wxss        # 全局样式
├── components/     # 自定义组件
├── images/         # 图片资源
├── locales/        # 多语言文件
├── pages/          # 页面文件
├── services/       # 服务层
├── types/          # TypeScript类型定义
└── utils/          # 工具类
```

## 核心功能

- 首页、分类页浏览商品
- 商品详情查看与规格选择
- 购物车管理
- 订单创建、支付、查询
- 用户中心与地址管理
- 积分系统
- 多语言支持

## 开发与构建

使用微信开发者工具打开 SutWxApp/ 目录进行开发。
