## 1. 概述

### 1.1 文档目的

本文档定义了苏铁微信小程序（SutWxApp）的功能规范，详细描述各功能模块的需求、实现标准和质量要求，确保开发团队对功能有一致的理解和执行标准。本文档与代码实现和原型设计保持颗粒度对齐。

### 1.2 适用范围

本文档适用于 SutWxApp 项目的所有功能开发、测试和验收工作，包括但不限于：

- 商品浏览与搜索功能
- 用户管理功能
- 购物车与订单管理功能
- 收货地址管理功能
- 帮助中心功能
- 设置功能
- 积分系统功能
- 社交功能

## 2. 首页模块

### 2.1 功能描述

首页是用户进入小程序的主要入口，展示轮播图、分类导航、推荐商品列表和搜索入口，提供核心的商品浏览和发现功能。

### 2.2 功能需求

| 需求编号 | 需求描述 | 优先级 | 验收标准 | 实现状态 |
|---------|---------|--------|----------|----------|
| FR-HM-001 | 轮播图展示 | P0 | 支持多张图片轮播，自动播放，点击可跳转 | 已完成 |
| FR-HM-002 | 分类导航入口 | P0 | 展示一级分类，点击进入分类页 | 已完成 |
| FR-HM-003 | 推荐商品列表 | P0 | 商品卡片展示，支持下拉刷新和上拉加载 | 已完成 |
| FR-HM-004 | 搜索入口 | P0 | 顶部搜索栏，点击进入搜索（开发中） | 部分完成 |
| FR-HM-005 | 商品收藏 | P1 | 点击收藏按钮切换收藏状态 | 已完成 |
| FR-HM-006 | 商品分享 | P1 | 支持分享到微信好友和朋友圈 | 已完成 |
| FR-HM-007 | 用户信息展示 | P1 | 显示用户头像、昵称、积分 | 已完成 |

### 2.3 交互设计

1. **页面加载**：进入页面时加载轮播图、分类和商品列表
2. **下拉刷新**：下拉手势触发刷新，重新加载商品列表
3. **上拉加载**：滚动到底部加载更多商品
4. **商品点击**：点击商品卡片跳转商品详情页
5. **分类点击**：点击分类标签筛选该分类下的商品
6. **轮播图点击**：点击轮播图跳转对应链接（仅允许跳转已注册页面）

### 2.4 数据结构

```javascript
// 首页数据结构
{
  bannerList: [
    {
      id: 1,
      imageUrl: String,    // 轮播图图片地址
      link: String         // 跳转链接
    }
  ],
  categoryList: [
    {
      id: Number,
      name: String,
      icon: String
    }
  ],
  productList: [
    {
      id: Number,
      name: String,
      desc: String,
      image: String,
      price: Number,
      priceText: String,
      sales: Number,
      isFavorite: Boolean
    }
  ]
}
```

## 14. 安全要求

### 14.1 数据安全

- 用户敏感信息加密存储（当前使用 Base64 编码，需升级为 AES 加密）
- 传输过程使用 HTTPS
- 手机号等敏感信息展示时脱敏
- 防止 SQL 注入和 XSS 攻击

### 14.2 接口安全

- 身份认证：JWT Token
- 请求签名：参数签名验证（需从 MD5 升级为 SHA-256）
- CSRF Token：防止跨站请求伪造（需使用安全随机数）
- 频率限制：防止恶意请求

### 14.3 已知安全问题

详细安全风险和修复建议请参考安全报告 `security_best_practices_report.md`。
