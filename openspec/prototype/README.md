# SutWxApp 原型文件

## 原型文件说明

本目录包含 SutWxApp（苏铁微信小程序）的高保真交互原型。原型采用极简主义设计风格，完整展示了小程序的核心页面和交互流程。

- **主原型文件**：`prototype.html`
- **当前版本**：3.0.0
- **更新日期**：2026-07-06

## 如何查看

1. 使用浏览器直接打开 `prototype.html` 文件
2. 推荐使用 Chrome、Safari、Firefox 等现代浏览器
3. 原型为响应式设计，支持桌面端和移动端预览
4. 点击左侧页面列表可切换不同页面
5. 支持页面间的交互跳转和动画效果

## 包含的页面列表

| 序号 | 页面名称 | 页面标识 | 说明 |
|------|----------|----------|------|
| 01 | 首页 | home | 浏览精选商品，发现优质绿植 |
| 02 | 分类 | category | 按分类浏览商品 |
| 03 | 商品详情 | productDetail | 查看商品详细信息、规格选择、用户评价 |
| 04 | 购物车 | cart | 管理购物车商品、结算 |
| 05 | 确认订单 | orderConfirm | 确认订单信息、选择地址、提交订单 |
| 06 | 我的订单 | orderList | 查看订单列表、订单状态 |
| 07 | 个人中心 | userCenter | 用户信息、订单入口、功能菜单 |
| 08 | 地址管理 | address | 管理收货地址 |
| 09 | 设置 | settings | 应用设置、账号管理 |

## 设计特点

- **极简主义设计**：简洁清爽的视觉风格
- **绿色主题**：以绿色为主色调，契合绿植电商定位
- **高保真交互**：模拟真实小程序的交互动效
- **完整流程**：覆盖浏览、选购、下单全流程
